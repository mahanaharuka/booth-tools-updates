# booth-tools-updates

BOOTH で配布しているツールの、更新の案内に使う情報だけを置く場所です。

各ツールは起動時に `<ツールの id>/manifest.json` を読み、新しい版が公開されていれば、利用者に案内します。
利用者が承認したときだけ、BOOTH から入手した ZIP で入れ替えます。

- `manifest.json` … 版番号、変更点、配布 ZIP のファイル名・大きさ・SHA-256
- `manifest.json.sig` … 上のファイルへの署名（ツール側で確かめ、一致しない情報は使いません）

ここにはプログラム本体もソースコードも置いていません。
